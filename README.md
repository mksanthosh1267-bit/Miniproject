The Project Submission Portal is a Java Swing–based application designed to help students submit their academic projects along with document uploads. It provides fields for entering the student’s name, roll number, and project title, along with a user-friendly file chooser for uploading PDF or DOC files. The interface includes validation to ensure all required details are entered before submission, and it provides clear visual feedback for file selection. This project is ideal for beginners learning Java Swing, GUI design, and basic file handling concepts, offering a simple yet functional system that simulates real-world academic submission workflows.
